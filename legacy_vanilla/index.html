Pushing to GitHub Without Git

Since Git is not installed locally on this machine, you have 3 quick ways to sync this project to your repository:

1

Drag & Drop via GitHub Web

Open shishir18ravishankar/Lakshya-Ai in your browser. Click "uploading an existing file", drag these project files into the browser, and click Commit changes.

2

In-Browser VS Code (github.dev)

Press the . (dot) key on your GitHub repository page or visit https://github.dev/shishir18ravishankar/Lakshya-Ai to edit, commit, and push straight from your browser.

3

GitHub REST API (Automated)

We've included a ready-to-use PowerShell script (sync-to-github.ps1) in this workspace. With a personal GitHub token, you can push files directly via API!
